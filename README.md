# MyOS Judgment Radar

This repository is the public visualization layer for selected MyOS judgments.

## Role

- Authority: Obsidian / MyOS remains the source of truth.
- Presentation: GitHub Pages shows public summaries, status, and selected HTML briefs.
- Maintenance: Codex updates this repository after reviewing MyOS metadata and receiving user confirmation.

## Current Pages

- Home: `index.html`
- Published briefs: `v002.html`, `v014.html`
- Radar data: `data/judgments.json`

## Operating Rule

Do not treat this repository as the canonical judgment library. If content differs from MyOS, MyOS wins.

Public pages should avoid copying full private working notes unless the judgment has been explicitly approved for publication.
