# Judgment Lab

An interactive map of judgment themes, individual views, and the relationships between them.

**Live site:** [ivy-jt.github.io/opinions](https://ivy-jt.github.io/opinions/)

## Current Snapshot

- 25 mature judgments
- 9 long-term themes
- 21 judgment relationships
- 9 readable briefs

## Site Structure

- `index.html` - theme map, relationship graph, and judgment index
- `data/judgments.json` - structured public data
- `v*.html` - readable judgment briefs
